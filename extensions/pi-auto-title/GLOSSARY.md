# Auto-title

This extension names sessions from their first request.

## Language

**Temporary title**:
The initial session title taken from the request while a generated title is
pending. It remains if generation fails.

**Title model**:
The model used to generate a session title, independently of the model
answering the request.

**Model pin**:
A saved preference for a specific title model instead of following the current
session model.
_Avoid_: Session model override
